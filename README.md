## Description: 
**NetPractice** is a networking project designed to introduce the fundamentals of computer networking through practical exercises.

The goal of this project is to understand how networks operate by configuring IP addresses, subnet masks, and routing tables to establish communication between devices.

Through a series of networking exercises, the project helps develop a solid understanding of key networking concepts, including TCP/IP addressing, subnetting, and routing. Each exercise involves analyzing a network diagram, identifying configuration issues, and adjusting network settings to ensure that devices can communicate correctly.

By completing this project, students gain practical knowledge of how devices communicate within a network and how data travels between different networks.


## Instructions

### Installation

NetPractice is a browser-based networking project. It does not require compilation or the installation of additional software.

To get started:

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```
2. Navigate to the project directory:

   ```bash
   cd NetPractice
   ```

### Execution

1. Open the NetPractice training interface in your web browser.
2. Start with **Level 1** and progress through the 10 networking exercises.
3. Analyze the network diagram provided for each level.
4. Configure the IP addresses, subnet masks, and routing tables to establish proper communication between devices.
5. Use the **Check** feature to verify your configuration.
6. Once the level is validated, export your configuration if required and proceed to the next level.

### Completion

The project is considered complete when all 10 levels have been successfully configured and validated.

No compilation or execution of source code is required, as the project focuses on practical network configuration exercises.
